# Weather Forecast App

A simple weather forecast application built with vanilla JavaScript and Webpack.  
**Live demo:** [https://weather-forecast-one-fawn.vercel.app/](https://weather-forecast-one-fawn.vercel.app/)

## Features
- Search for any city worldwide
- Displays current conditions, today's forecast, and next 7 days
- Responsive design

## Setup
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file in the root and add your Visual Crossing API key:
```

VC_API_KEY=your-key-here

```
4. Run `npm start` to start the development server.
5. Build for production with `npm run build`.

## Built With
- JavaScript (ES modules)
- Webpack 5
- CSS3
- Visual Crossing Weather API
